# Content

Hunting knowledge lives here as data, not code (spec §0.4, §6). The founders review and edit these
files; the app and the engine read them.

Planned layout (filled in from M2 on):

```
whitetail/phases.yaml      season phases + "What to do now"     (M3)
whitetail/tips.yaml        Hunt Mode tip rules                  (M3)
whitetail/calling.yaml     calling rules                         (M3)
whitetail/placement.yaml   stand placement basics                (M3)
whitetail/sign.yaml        reading sign                          (M1/M3)
lessons/*.md               offline lessons                       (M3)
regulations/<STATE>.yaml   per-state rules with sources          (M2)
ai/system-prompt.md        AI coach guardrails                   (M4)
engine.yaml                overrides for hunt-engine constants   (M2)
```

Every piece of advice carries `evidence: research | consensus | mixed`. When something is unclear,
add a `# QUESTION:` comment rather than guessing.
